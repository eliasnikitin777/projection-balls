# Проекции — шарики в кубе

Браузерный прототип: вращайте прозрачный куб, чтобы соединять экранные проекции шариков одного цвета в желейные цепочки.

**Играть:** https://eliasnikitin777.github.io/projection-balls/

## Управление

- Перетаскивайте мышью или пальцем, чтобы повернуть куб.
- Серая кнопка справа сверху открывает настройки размера шара и расстояний соединения и разъединения.
- Reset применяет настройки и возвращает статичный уровень в начальное положение.

Связи определяются экранным зазором между проекциями. Существующая связь держится до выбранного расстояния разъединения. Позиции шариков и начальный ракурс предустановлены.

## Локальный запуск

Откройте `index.html` в браузере. Зависимости и сборка не нужны.

## Публикация

GitHub Actions публикует `index.html` и `main.js` в GitHub Pages после каждого push в `main`. Workflow также можно запустить вручную.
